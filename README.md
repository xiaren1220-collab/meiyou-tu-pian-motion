# 点滴选择栏动效 Demo

打开 index.html，或运行 `python3 -m http.server 4174` 后访问 http://127.0.0.1:4174/。部署时上传整个文件夹，无需安装依赖。

默认展示「方案1（单层 最终选用）」，可切换到保留原有交互的「方案2（双层 废弃）」。在单层方案中，点击相机或加号打开选择栏，再选择拍照或相册。相册支持多选并按选择顺序添加，图片栏最多 9 张，支持删除和横向拖动。

拍照和相册为交互演示：使用 Figma 相机素材及生成的示例餐食图片，不调用设备相机或系统相册。面板返回按钮恢复选择栏，点击面板外空白收起面板；进入前若键盘展开，面板覆盖键盘，键盘保持原状。

相机/相册面板依据 Figma 设计以 378×504 逻辑像素显示，进入 300ms 缓出，退出 250ms 缓入；其余原有输入栏、键盘和选择栏过渡沿用 Demo 现有参数。项目使用本地素材，不依赖临时图片链接。
